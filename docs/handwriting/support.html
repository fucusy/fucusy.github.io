Keep paper diaries searchable, with the original pages close at hand.

纸迹可寻 (Chinese Handwriting Collection) imports photos of handwritten Chinese diaries and PDF books, and organizes entries for local text and date search.

Import photos and review

In Collection, tap + → Choose from Library and select existing diary photos. Arrange the pages and tap Create Entry. Use Library to add more pages. There is no in-app camera or document-scanner capture. Recognition runs locally on a supported real iPhone or iPad; the simulator cannot run recognition. Compare the transcript with the page image and correct any errors.

Import a PDF book

Tap + → Import PDF. Select pages and review “Start a new entry” for each page; turn it off for continuation pages. For PDFs containing selectable text, you can reuse that text and split at full dated headings, including several entries on one page. Scanned PDFs use manually reviewed page boundaries and on-device recognition. Open an entry’s original PDF to return to the source page.

Limits: 250 MiB per PDF, up to 2,000 pages, and 20 pages per manually grouped entry. Provide an unlocked copy of password-protected files.

Search your writing

Open Search and try a topic, phrase, or date such as “和家人旅行”, “2026年4月”, or “last month family”. Search works on saved text, with Chinese normalization, related terms, and dates. It retrieves matching entries; it does not generate answers. Correct recognition errors to improve results.

Backup and restore

Use Settings → Export & Import for ZIP backups, or Settings → iCloud Backup for optional snapshots in your own iCloud Drive. iCloud requires an Apple account, iCloud Drive enabled, available storage, and network access. It is not live sync. Keep a separate verified backup and test restoration before discarding paper. ZIP exports are not encrypted by the app.

Recognition or import problems

Use sharp, well-lit page images with all page edges visible. Recognition is resource intensive; allow time, keep the app open, and retry a failed entry. If a PDF cannot be opened, check its size, page count, and password protection. If the bundled model is missing, preserve a backup before reinstalling; do not delete your only copy of the archive.

Privacy and deletion

No app account is required. For local storage, optional iCloud, exports, and deletion instructions, read the privacy policy. Copying text into an external AI app is your choice and is governed by that service’s policy.

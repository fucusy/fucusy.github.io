隐私政策

更新日期：2026年11月15日

手写内容属于你。文字识别与搜索在设备上进行，开发者不会收到你的日记档案。

本政策适用于 Qiang Chen 开发的 纸迹可寻（中文手写日记收藏），应用标识为 ai.hula.HandwritingCollection。本政策说明 iPhone、iPad 应用以及下述网站和支持服务的数据处理方式。

应用保存哪些内容

导入的页面图片、原始 PDF、识别文字、日记日期、修改内容和设置保存在应用的本地存储中。中文手写识别与搜索在设备上完成，无需注册应用账户。应用没有广告、跟踪、开发者统计 SDK 或云端 AI 服务。我们不出售日记信息，也不用日记训练模型。

可选的 iCloud 备份

开启自动 iCloud 备份或选择“立即备份”后，应用会将 ZIP 快照写入你自己的 iCloud 云盘。iCloud 由 Apple 按照你的 Apple 账户设置和 Apple 隐私政策提供，开发者无法访问这些备份。应用保留其管理的最新五份备份。关闭自动备份只会停止后续自动快照，不会删除已有副本。这是快照备份，并非多设备实时同步。设备本身的 Apple 备份设置也可能包含应用数据，与本功能相互独立。

权限

  • 照片与文件：通过系统选择器导入你选中的图片或文档。
  • 通知：可选的本地识别任务进度通知；应用不会把日记发送到开发者的推送服务。

当前应用不访问相机，也不请求相机权限。图片和文档通过系统选择器选取。你可以在 iOS 设置中管理通知和 iCloud 设置。

分享、导出与外部 AI

复制文字、分享日记或导出 ZIP 均由你主动操作。接收方和存储服务将按照各自的政策处理副本。将文字粘贴到外部 AI 应用时，该服务会收到内容；本应用不会自动发送给外部 AI。应用不会对 ZIP 导出文件额外加密，请妥善保存并谨慎选择分享目的地。

你的选择与删除方式

  • 在收藏列表中编辑或删除日记。同一原始 PDF 如仍被其他日记引用，会继续保留；删除一段摘录不会涂除原始 PDF 的内容。
  • 如需完整移除某个 PDF 的内容，请删除所有关联日记，并单独移除包含该 PDF 的备份和导出副本。
  • 在“设置 → 导出与导入”中获取可携带的档案副本。
  • 在“设置 → iCloud 备份”中关闭自动备份，并在该页面或“文件 → iCloud 云盘 → Chinese Handwriting → Backups”删除已有备份。“文件”的“最近删除”中可能仍保留副本。
  • 删除日记或卸载应用不会删除旧 iCloud 快照、设备备份、其他位置的导出文件或已发送给其他服务的副本，请在相应服务中单独管理。
  • 若要移除全部本地应用数据，请使用“iOS 设置 → 通用 → iPhone/iPad 储存空间 → 本应用 → 删除 App”。“卸载 App”会保留数据。本地临时导出和诊断文件可能保留至应用或系统清理，或删除 App。

开发者没有你的档案副本，无法远程取回或删除。应用没有需要注销的账户。

模型文件与诊断

识别模型随应用安装。第 1、2 号构建包含一个后备路径：若找不到内置模型，可能从 Hugging Face 下载公开模型文件。此请求不会上传日记页面，但下载服务会收到 IP 地址等普通网络信息。从第 3 号构建开始，后备下载已移除；缺少模型时会显示错误。应用不向开发者上传本地诊断日志。Apple 可能依据其设置和政策提供 TestFlight 反馈及崩溃诊断。

网站与支持

这些页面没有广告或统计脚本。GitHub Pages 和 Cloudflare 托管网站，可能为网页传输与安全处理 IP 地址等常规请求信息。访问网站不会上传日记。你主动发送支持邮件时，我们会收到邮件地址、正文和你附加的文件，并用于回应请求。除非必要，请勿发送私人日记页面。如需删除支持邮件，可联系我们；适用的保留义务可能影响删除范围。

更新与联系
